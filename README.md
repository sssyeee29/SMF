📦 Smart Milk Factory Project -- 비전을 통한 우유 불량 검출 프로젝트

개발 배경: "불량 검출도 이젠 AI"

식품 산업에서 불량 제품은 소비자 신뢰를 떨어뜨리고 기업에 손실을 
초래하는 중요한 문제입니다. 
특히 신선식품인 우유는 유통 과정에서 포장 손상이나 찌그러짐 등 
다양한 불량이 발생할 수 있습니다. 
기존의 육안 검수 방식은 시간이 오래 걸리고 정확도가 낮아
대량 생산 환경에 적합하지 않습니다. 
이에 따라 AI와 컴퓨터 비전 기술을 활용해 불량을 실시간으로 탐지하고
자동화하는 스마트 밀크 프로젝트를 기획하게 되었습니다.
